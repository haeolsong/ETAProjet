## 공통

- `venv/bin/python` 으로 실행한다. 셸의 `python` 은 다른 인터프리터일 수 있다.
- 수정 후 `venv/bin/ruff check` · `ruff format` 을 돌린다.

## collect_flights.py — 되돌릴 수 없는 데이터

**API 는 D-3 까지만 준다. 나흘을 놓치면 그 날짜는 영구히 복구 불가다.**
이 파일을 고칠 때는 수집이 멈추는 실수가 가장 비싸다. 수집 경로를 건드렸으면
반드시 한 번 실행해 결과를 확인한다.

전처리에서 이미 처리 중인 API 함정들(README 에 근거 있음):

- **코드쉐어 중복** — `masterflightid` 는 코드쉐어 행에만 채워진다. 단독편은 전부 결측이라
  `flightid == masterflightid` 로 거르면 정상 항공편이 통째로 날아간다.
  조건은 **결측이거나 주편명인 행**이고, 그 뒤에도 `fid` 중복 제거가 더 필요하다.
- **미확정편** — `rmkKor == '도착'` 인 행만 쓴다. `사전결항` 은 예정시각이 그대로 들어와
  지연 0분으로 보인다.
- **필드명 불일치** — 도착은 `arrAirportCode`, 출발은 `arrvAirportCode`.
- `numOfRows` 는 최대 100(문서에 없음). 오류도 HTTP 200 으로 오므로
  본문의 `OpenAPI_ServiceResponse` 유무로 판별한다.

## collect_metar.py

- 요청 파라미터에 `tz=Asia/Seoul` 을 넘겨 **KST 로 받는다.** 이걸 빼면 병합이 9시간 어긋나는데,
  METAR 가 24시간 있어서 커버리지만 봐서는 안 드러난다.
- `precip_mm` 은 RKPK 가 보고하지 않아 **항상 0** 이다. 피처로 쓰지 않는다.
- 아카이브에 산발적 결측이 있다(전체 0.18%, 가끔 하루 5~10시간). **정상이므로 메우지 않는다.**
  재수집해도 채워지지 않는다 — 2026-09-07 새벽에서 확인했다.
- 지난 연도 파일은 건너뛰지만, **이듬해 1월 2일 전에 받은 파일(mtime 기준)은 연말분이 빠져 있어
  다시 받는다.** 판정이 mtime 이라 **연말 전에 받은 파일을 복사하면 완결로 오인된다** — 옮긴 파일이 의심되면 `--force`.

## train.py

- **시계열이므로 랜덤 분할 금지.** `split_by_time()` 을 쓴다.
- **표본이 다르면 MAE 를 직접 빼지 말 것.** 사전예측은 전체, 이륙후는 출발지연 보유분(29%)
  에서 학습된다. 비교하려면 `--dep-delay-only`.
- **MAE 만으로 결론내지 말 것.** 지연이 0 근처에 몰려 있어 상수 예측인 베이스라인도 MAE 를
  낮게 받는다(`--dep-delay-only` 부분집합에서는 아직 베이스라인이 9.71 로 사전예측 11.39 를
  앞선다). 그러나 15분 이상 지연은 한 건도 못 잡아 **적중률이 0%** 다 — 중앙값이 음수라
  한 번도 경고하지 않기 때문이다. 적중률·오경보율을 함께 본다.
  근거: `notebooks/02_error_analysis.ipynb` §3
- `metrics.csv` 는 열이 늘어나면 header 없는 append 가 깨지므로 **읽어서 concat 후 재작성**한다.
  지표를 추가할 때 이 구조를 유지한다.
- **성능을 끌어올리려 하지 말 것.** 하이퍼파라미터든 파생변수든 지금 만지면 테스트셋에
  맞춘 과적합이 된다. 학습곡선이 **570편에서 평평해졌다** — 표본의 양은 이미 포화이고,
  남은 병목은 기상 다양성이다. 초기 9일치는 전 기간이 맑아 기상 피처 11개 중 6개가
  상수다(시정은 고유값 1개). 즉 지금 모델은 사실상 기상을 쓰지 않는다.
  근거: `notebooks/03_climate_feasibility.ipynb`

  실패한 시도를 반복하지 말 것 — 혼잡도(±30분 도착편 수)와 직전 1시간 평균지연은
  지연과의 상관이 0.05·0.09 로 신호가 없고, 넣으면 MAE 가 12.70 → 12.85·13.60 으로
  나빠진다. 횡풍 추가(`3f92853`) 때와 같은 패턴이다.

  > 1,297편 시점에 사전예측이 베이스라인을 처음 앞섰다(MAE 12.86 대 14.22, R2 0.17).
  > 527편 시점의 "사전예측이 베이스라인에 진다" 는 더 이상 맞지 않는다.
